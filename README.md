# Contour Website

Static website for https://github.com/MinchexBG/Contour.

The complaints page uses GitHub Issues. No GitHub token is stored in the website: submissions open a pre-filled GitHub Issue, and public issues are read through GitHub's API.

For GitHub Pages, copy this `website` folder's contents into the repository's Pages source (or the repository root if using the root as the Pages source), then enable Pages in Settings → Pages.
